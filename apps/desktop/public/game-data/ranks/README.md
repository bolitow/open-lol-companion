# Emblèmes de rang League of Legends

Images originales Riot Games, sans modification, extraites le 3 octobre 2026 de :
https://static.developer.riotgames.com/docs/lol/ranked-emblems-latest.zip

Documentation : https://developer.riotgames.com/docs/lol#ranked-info_icons-and-emblems

Les dix fichiers `Rank=*.png` sont renommés en minuscules pour l’application. Ils sont embarqués pour fonctionner sans téléchargement au rendu. Les rangs absents/non classés gardent un pictogramme neutre ; aucun emblème ne sert à déduire ou estimer un rang.

League of Legends et ces visuels appartiennent à Riot Games. Open LoL Companion n’est ni approuvé ni sponsorisé par Riot Games.
