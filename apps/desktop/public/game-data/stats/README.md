# Icônes de statistiques League — 16.19

Ressource graphique Riot Games, distribuée par CommunityDragon. Utilisation dans l'application communautaire sans affiliation à Riot. Les autres éléments de l'atlas ne sont pas affichés.

- Atlas source : https://raw.communitydragon.org/16.19/game/uiautoatlas/ux/fonts/css/stylesheet/atlas_0.png
- Rectangles source : https://raw.communitydragon.org/16.19/game/ux/fonts/css/stylesheet.cdtb.json
- Noms sémantiques du jeu : https://raw.communitydragon.org/16.19/game/ux/fonts.cdtb.bin.json (`UX/Fonts/CSS/StyleSheet/icons`).
- Import : 2 octobre 2026 ; fichier original non redessiné. L'interface utilise des sprites CSS, sans réseau au rendu.
- Version, SHA-256, source de chaque rectangle et dimensions : `src/app/statIcons.json`.

Famille `assets/ux/fonts/texticons/lol/statsicon/` : AD, AP, armure, RM, PV, mana, vitesse d'attaque, critique, déplacement, régénérations, accélération, récupération, portée, puissance soins/boucliers. Les couleurs des chiffres sont des tokens d'interface inspirés des pictogrammes, ajustés au contraste des thèmes sombre/clair ; ce ne sont pas des valeurs hexadécimales officielles revendiquées.

Les images ne fournissent aucune donnée de calcul : un coefficient AP/AD absent du catalogue reste absent. La mise en couleur d'une expression chiffrée n'utilise que son texte source affichable et conserve intégralement ce texte.
